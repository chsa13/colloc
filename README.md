# Подготовка к экзаменам ЦУ

Сайт: **https://chsa13.github.io/exams/**

Сборник тренажёров к коллоквиумам и контрольным. Каждый экзамен устроен одинаково: справочник по теории,
карточки, доказательства по шагам, банк задач с подсказками и решениями, пробник с таймером. Прогресс хранится в браузере.

| Экзамен | Когда |
|---|---|
| [Коллоквиум по матанализу](https://chsa13.github.io/exams/matan-colloc) | 26–30 октября |
| [Коллоквиум по основам матанализа и линейной алгебры (МИА)](https://chsa13.github.io/exams/mia-colloc) | 2–6 ноября |
| [КР2 по линейной алгебре](https://chsa13.github.io/exams/linal-kr2) | 5 ноября |
| [Коллоквиум по матанализу, пилотный поток](https://chsa13.github.io/exams/pilot-colloc) | 18 ноября |

Неофициальный конспект от студентов по программе курсов, не заменяет материалы курса.

```
npm install
npm run dev     # локально
npm test        # проверки контента и движка
```

Как устроено и как добавить экзамен — [DESIGN.md](DESIGN.md).
