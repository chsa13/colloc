## 2. Система подготовки

### 2.1 База знаний: атомарные «единицы»

Единица = один пункт из списка вопросов (например, «Теорема о зажатой последовательности»).
У неё до трёх «граней», и **у каждой грани свой уровень**:

- **Определение / формулировка** — точный текст + запись в кванторах.
- **Доказательство** — разбито на шаги (5–10), у каждого шага короткое название («выбираем N = max(N₁, N₂)»).
- **Опора**: одна строка «идея», типичные ошибки, на какие единицы ссылается (лемма 1 → Больцано–Вейерштрасс), ссылка на лонгрид.

Пример: «Теорема об обратной функции» — формулировка 🔴, доказательство ⚫.
Поэтому фильтр уровня работает по граням, а не по темам.

### 2.2 Типы заданий (тренажёры)

| Режим | Что делает | Проверка |
|---|---|---|
| **Карточки** (опр./формулировки) | Название → вспомни → открой ответ | Самооценка: «не знаю / частично / знаю» |
| **Кванторы** | «Запиши lim_{x→3−0} f(x) = −∞ в кванторах»; отрицание определений | Автогенератор: тип точки (a, a±0, ±∞, ∞) × тип предела (A, ±∞, ∞) × (функция / последовательность). Сверка с эталоном + собрать запись из блоков |
| **Доказательство по шагам** | Шаги открываются по одному; режимы «расставь шаги по порядку» и «что пропущено?» | Порядок — автоматически; содержание — самооценка по шагам |
| **Верно / неверно** | «Всякая ли ограниченная последовательность сходится?» | Ответ да/нет + обязательный контрпример/аргумент, затем эталон |
| **Задачи** | Дирихле, стандартные пределы (aⁿ/n!, n^k/aⁿ, ⁿ√n, ⁿ√a, logₐn/n), задачи из контрольных | Подсказки уровнями (идея → план → решение) |
| **Пробный билет** | Генерация билета по структуре демо, таймер 45 мин | Затем фаза «ответа»: открываем эталоны, отмечаем баллы по критериям → итог из 11 |

### 2.3 Повторение и прогресс

- У каждой грани статус: `new → weak → shaky → known`. До коллоквиума считанные дни, поэтому вместо долгих интервальных схем — очередь «сначала слабое, потом давно не виденное».
- **Карта готовности**: таблица «тема × (опр / форм / док)» с цветом, плюс прогноз баллов по красному.
- Кнопка «Режим последнего вечера»: только то, что ещё `weak/shaky`, плюс все формулировки из доказательств.

### 2.4 Уровень (основной / + продвинутый)

- Переключатель в шапке: **🔴 Основной** / **🔴+⚫ Основной + продвинутый**. Хранится в браузере.
- 🔴: ⚫-грани скрыты, в пробном билете вопросы 7, 10, 14 заменяются на 🔴 или показаны серыми с пометкой «не идёт в зачёт».
- 🔴+⚫: всё видно, у каждого вопроса значок уровня, счёт по двум шкалам отдельно.

### 2.5 Справочник

Весь материал по темам с поиском — как удобный сборник, ссылки «где в лонгриде».
Плюс страница «Как отвечать»: регламент, распределение 45 минут, что проверяет экзаменатор.

## 3. Архитектура

### Рекомендация: статический сайт без сервера

Времени мало, а нужно только раздавать контент и хранить личный прогресс — сервер не нужен.

```
Vite + React + TypeScript   — SPA
KaTeX                       — формулы
content/*.ts               — база знаний (типизирована схемой src/content/schema.ts)
localStorage                — прогресс и настройки (экспорт/импорт JSON)
Хостинг: GitHub Pages / Vercel / ссылка claude.ai — одна ссылка для всех
```

Аккаунты и общая база прогресса — не в первой версии (можно позже через лёгкий бэкенд, если понадобится рейтинг или общая статистика).

### Модель данных

```ts
type Level = 'basic' | 'advanced';            // 🔴 / ⚫
type Kind  = 'definition' | 'statement' | 'proof';

interface Unit {
  id: string;                 // 'seq-squeeze'
  topic: TopicId;             // 'seq-limit-2'
  title: string;              // 'Теорема о зажатой последовательности'
  source: string;             // 'Лонгрид 10, теорема 2'
  facets: {
    definition?: { level: Level; text: string; quantifiers?: string };
    statement?:  { level: Level; text: string };
    proof?:      { level: Level; idea: string; steps: { title: string; body: string }[] };
  };
  pitfalls?: string[];
  uses?: string[];            // id единиц, на которые опирается
}

interface Task {
  id: string; topic: TopicId; level: Level;
  type: 'quantifiers' | 'true-false' | 'prove' | 'compute' | 'can-we-claim';
  points: number;
  prompt: string; hints: string[]; solution: string;
  source?: string;            // 'демо-билет №13', 'КР-2025 вар.1 №3'
}

interface Progress {          // localStorage
  level: 'basic' | 'basic+advanced';
  facets: Record<`${string}:${Kind}`, { status: 'new'|'weak'|'shaky'|'known'; seen: number; last: number }>;
  mocks: { date: number; red: number; black: number; items: ... }[];
}
```

### Страницы

```
/                 Главная: переключатель уровня, карта готовности, «что учить сейчас»
/topics/:id       Справочник по теме
/unit/:id         Единица: формулировка, доказательство по шагам, связи
/drill/cards      Карточки (фильтры: тема, тип, только слабые)
/drill/quant      Тренажёр кванторов
/drill/proof      Доказательства (шаги, порядок, пропуск)
/drill/tasks      Задачи
/mock             Пробный билет (подготовка → ответ → самооценка → итог)
/how              Как отвечать на коллоквиуме
```

### Структура проекта

```
content/
  index.ts                  # список тем в порядке курса + задачи
  sets.ts, sequences.ts, …  # темы: Topic { units: Unit[] }, тексты — md`…` (Markdown + $LaTeX$)

  engine/    queue.ts (что учить), ticket.ts (генератор билета), quant.ts (генератор кванторов)
  store/     progress.ts (localStorage + экспорт/импорт)
  ui/        Math.tsx, LevelBadge.tsx, ...
  pages/
```

## 4. Наполнение контентом

1. Каркас из списка вопросов → `topics.yaml` + пустые единицы с уровнями по граням.
2. Тексты из «основного уровня» и «Сборника», сверка с лонгридами; формулы в LaTeX.
3. Доказательства разбиваются на шаги вручную (это основная ценность сайта).
4. Задачи: демо-билет, упражнения лонгридов, контрольные 2025 (основной уровень).
5. Проверка: сборка падает, если у единицы нет уровня или битая формула.

## 5. План работ (с учётом сроков)

| Этап | Что | Результат |
|---|---|---|
| **MVP** | Справочник + карточки + переключатель уровня + все 🔴 единицы | Уже можно учить |

## 6. Правила контента (авторское право)

Репозиторий публичный, поэтому:
- **Не кладём файлы курса**: PDF лонгридов, сборников, контрольных, их текстовые выгрузки и скриншоты. Они только во временной папке вне проекта (`.gitignore` блокирует `*.pdf`, `*.txt`).
- **Пишем своими словами.** Определения и формулировки — математические факты, их можно излагать, но не копировать абзацами. Доказательства пересказываем своей разбивкой на шаги. Условия задач из контрольных переформулируем и меняем числа.
- В поле `source` указываем только ссылку вида «Лонгрид 10, теорема 2», без цитат.
